# Frozen data-source manifest

The analysis uses the files in `data/raw` exactly as recorded by `SHA256SUMS.txt`. The files were assembled on September 20, 2026. All transformed data are regenerated by `code/analysis/run_analysis.R`; the script does not fetch live data.

The same provenance is available in machine-readable form at
`data/SOURCE_MANIFEST.csv`. Running `code/pipeline/export_original_csv.py` creates a
deterministic CSV copy of every source under `data/original_csv/` and records
both the frozen-source digest and exported-file digest in
`data/original_csv/SHA256SUMS.csv`. The Yahoo exports add the source JSON digest
to every row; the five source CSVs are copied byte-for-byte.

| Frozen file | Variables | Public source |
|---|---|---|
| `Yahoo_HEWJ_chart.json` | HEWJ adjusted close | https://finance.yahoo.com/quote/HEWJ/history/ |
| `Yahoo_EWJ_chart.json` | EWJ adjusted close | https://finance.yahoo.com/quote/EWJ/history/ |
| `FRED_DEXJPUS_daily.csv` | Japanese yen per U.S. dollar | https://fred.stlouisfed.org/series/DEXJPUS |
| `FRED_NIKKEI225_VIXCLS_daily.csv` | Nikkei 225 close; VIX close | https://fred.stlouisfed.org/series/NIKKEI225 and https://fred.stlouisfed.org/series/VIXCLS |
| `FRED_US_Japan_rates_monthly.csv` | U.S. and Japan immediate/call-money rates | https://fred.stlouisfed.org/series/IRSTCI01USM156N and https://fred.stlouisfed.org/series/IRSTCI01JPM156N |
| `Japan_5_Factors_Daily.csv` | Japan Mkt-RF, SMB, HML, RMW, CMA, RF | https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html |
| `Japan_MOM_Factor_Daily.csv` | Japan momentum factor | https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html |

The iShares product pages document the economic interpretation of the matched fund pair: https://www.ishares.com/us/products/259624/HEWJ and https://www.ishares.com/us/products/239665/ishares-msci-japan-etfEWJ.

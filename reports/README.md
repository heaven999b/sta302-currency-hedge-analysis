# Reports / 汇报材料

This directory contains human-readable writing and rendered deliverables. It
does not contain the underlying experiment code or machine-readable result CSVs.

本目录只保存给人阅读的汇报材料；代码在 `code/`，实验数值在 `results/`。

## Analysis / 完整研究汇报

- `analysis/RESULTS_AND_CONCLUSIONS.md`: bilingual methods, findings, robustness,
  limitations and final conclusion.
- `analysis/STA302_Project_Analysis.html`: rendered self-contained analysis with
  code, tables and figures.

## Proposal / Proposal材料

- `proposal/STA302_Research_Proposal_EN.md`: English proposal source.
- `proposal/STA302_Research_Proposal_ZH.md`: Chinese proposal source.
- `proposal/STA302_Research_Proposal_Official_EN.pdf`: official English submission PDF.
- `proposal/STA302_Research_Proposal_Official_ZH.pdf`: complete Chinese PDF.
- `proposal/STA302_Bilingual_Research_Proposal.pdf`: bilingual study copy.

## Submission guidance / 提交说明

- `submission/QUERCUS_SUBMISSION_CHECKLIST.md`: manual steps and remaining
  group-member confirmations.

The separate top-level `submission/` directory is the generated package intended
for direct Quercus/OneDrive staging.

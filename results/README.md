# Results / 实验结果

This directory is the machine-readable source of truth for completed experiments.
Files are regenerated by `code/analysis/run_analysis.R`; do not edit result CSVs
by hand.

本目录保存已经跑出的机器可读实验结果，统一由R分析脚本生成，不应手工修改。

## Main inference / 核心推断

| Files | Meaning |
|---|---|
| `coefficients_classical.csv` | Full-model OLS coefficients with classical standard errors. |
| `coefficients_hac5.csv` | Same coefficients with primary Newey-West HAC(5) inference. |
| `fx_slope_hypothesis_tests.csv` | Pre/post slopes and tests against the complete-hedge benchmark of -1. |
| `diagnostics.csv`, `vif.csv` | Assumption tests, fit measures and multicollinearity diagnostics. |

## Rolling-origin model selection / 滚动选模

| Files | Meaning |
|---|---|
| `rolling_origin_fold_metrics.csv` | RMSE and MAE for every model in validation years 2021, 2022 and 2023. |
| `model_selection_rolling_origin.csv` | Three-fold means/SDs and the ranking used to select the FX-interaction model. |
| `heldout_test_metrics.csv` | One-time 2024-2026 test comparison with historical-mean and zero benchmarks. |
| `heldout_test_predictions.csv` | Row-level final-test actual and predicted values. |
| `split_summary.csv` | Development and untouched-test date boundaries. |

## Robustness / 稳健性

| Files | Meaning |
|---|---|
| `functional_form_sensitivity.csv` | Linear, quadratic and Yeo-Johnson comparison. |
| `yeo_johnson_lambda_profile.csv`, `yeo_johnson_rolling_folds.csv` | Transformation selection evidence. |
| `hac_lag_sensitivity.csv` | HAC lag 1/5/10 comparison. |
| `influence_audit.csv`, `influence_sensitivity.csv` | Cook-distance audit and influence stress tests. |
| `break_date_sensitivity.csv` | March 6/11/16 pandemic-break comparison. |
| `data_alignment_audit.csv`, `data_alignment_sensitivity.csv` | Exact return-interval checks and looser-alignment sensitivity. |

## Reproducibility / 复现证据

| Files | Meaning |
|---|---|
| `data_quality_audit.csv` | Machine-checked dates, missingness, intervals and split isolation. |
| `models.rds` | Fitted R model objects and locked model-selection metadata. |
| `R_run_log.txt` | Software versions and complete run summary. |
| `ARTIFACT_MANIFEST.csv` | SHA-256 manifest for core repository artifacts. |
